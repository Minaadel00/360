# 360

## نموذج الدخول وإدارة المستخدمين

- افتح `login.html` من خلال متصفح حديث.
- حساب المدير التجريبي: `admin`، وكلمة المرور: `admin123`.
- من الصفحة الرئيسية يفتح المدير إدارة المستخدمين، ويمكنه إضافة الحسابات وتعديل الصلاحيات ونطاقات الفلاتر أو حذفها وإعادة تعيين كلمات المرور.
- نطاقات DM وMR مستقلة. ارفع ملف Excel في كل لوحة أولًا لتظهر قيم الشيت كاختيارات في إدارة المستخدمين؛ ويمكن تحديد أكثر من قيمة، والاختيار الفارغ يسمح بكل القيم في ذلك البعد.
- يرفع المستخدم ملف Excel الخاص باللوحة المسموح بها. تُطبّق نطاقات الفلاتر على السجلات قبل عرضها وحساب المؤشرات والتصدير.

## تنبيه أمني

هذا نموذج واجهة HTML فقط. الحسابات وكلمات المرور محفوظة في `localStorage` ويمكن تجاوز الدخول أو قراءة ملفات البيانات من المتصفح. لا تستخدمه مع بيانات حقيقية أو حساسة. يلزم backend وقاعدة بيانات ومصادقة وصلاحيات على الخادم قبل النشر الفعلي.
